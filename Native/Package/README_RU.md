# DMC5 DualSense Layer — Native C++

Это рекомендуемая версия мода для Devil May Cry 5 Steam. Она реализует полный
набор принятых функций: адаптивные курки с учётом текущих назначений,
расширенную вибрацию, подсветку персонажей и интерфейс DualSense.

## Требования

- Windows x64 и лицензионная Steam-версия Devil May Cry 5;
- DualSense, подключённый по USB;
- включённый Steam Input или настройка контроллера «Использовать настройки по
  умолчанию».

Архив самодостаточен. Устанавливать .NET, ViGEm, виртуальный контроллер или
отдельный драйвер не требуется. Bridge работает только во время игровой сессии
и закрывается вместе с DMC5.

USB — единственный полностью поддерживаемый и физически проверенный вариант.
Bluetooth считается экспериментальным: штатный ввод через Steam Input должен
сохраниться, но адаптивные курки, подсветка и обычная вибрация не гарантируются.
Расширенная хаптика в текущей реализации по Bluetooth работать не может из-за
отсутствия четырёхканального аудиовыхода DualSense.

Обычные DualSense семейств CFI-ZCT1 и CFI-ZCT2 используют общий тип
PS5-контроллера Steam и не требуют настройки под конкретную внутреннюю ревизию.
DualSense Edge принимается output-путём и matcher аудиоустройства, но полный
физический тест на Edge ещё не завершён. Весь набор эффектов требует USB.

Аудиовыход хаптики в первую очередь определяется по аппаратному идентификатору
Sony USB и четырёхканальному формату, а не по видимому имени в Windows. Поэтому
локализованное или изменённое пользователем имя не требует настройки.
`AudioDeviceContains` сохранён как резерв для необычных драйверов.

## Установка

1. Полностью распакуйте архив в отдельную папку.
2. Закройте DMC5 и запустите `INSTALL-DMC5-DualSense.cmd`.
3. Если от старой версии в параметрах запуска Steam осталась строка
   `DMC5DualSense.Launcher.exe`, один раз удалите её.
4. Запускайте игру обычной кнопкой «Играть». Команда запуска не требуется.

REFramework загружает игровой плагин, который скрыто запускает Bridge для
текущего процесса DMC5. Bridge закрывается вместе с игрой и не создаёт
постоянную службу или watcher. Launcher сохранён только как ручной резервный
вариант совместимости.

Для удаления запустите
`Devil May Cry 5\DMC5DualSense\UNINSTALL-DMC5-DualSense.cmd`. Установщик хранит
манифест и резервные копии заменённых файлов.

`TEST-DualSense.cmd` запускает аппаратный тест курков, подсветки и хаптики; он
не нужен для обычной установки.
