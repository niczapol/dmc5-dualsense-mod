# Архитектура DMC5 DualSense Layer 1.0

## Поток данных

```text
DMC5 / RE Engine
  ├─ персонаж, HP, оружие, L2/R2, Exceed и Blue Rose
  ├─ app.PadShake и низкоуровневые команды моторов
  └─ подтверждённые события оружия Nero, Dante и Vergil
            │
            ▼
REFramework.NET-плагин — только наблюдение
            │ UDP 127.0.0.1:27105
            ▼
DMC5DualSense.Bridge.exe
  ├─ точные таблицы эффектов ─────► USB HID ──► L2/R2 + lightbar
  ├─ оригинальные PS5 WAV ────────► WASAPI 4 ch ─► voice-coil actuators
  └─ штатные моторы PC-версии ────┬► WASAPI 4 ch
                                   └► USB compatible rumble
```

Steam Input остаётся единственным источником кнопочного ввода. UDP слушается только на
loopback. Ошибка HID или аудиоустройства изолирована от процесса игры.

## Почему мост должен стартовать первым

На исследованной конфигурации запуск DMC5 через Steam сначала открывает физический
DualSense средствами Steam Input. Плагин после этого загружается и передаёт события,
но внешний мост уже получает `DualSense not found`. Поскольку HID-команда включает
и курки, и lightbar, и режим совместимой отдачи, внешне одновременно пропадает всё.

`Launch-DMC5.ps1` решает гонку детерминированно:

1. убеждается, что DMC5 закрыта;
2. перезапускает мост;
3. ждёт новую строку `DualSense connected`;
4. ждёт `Advanced haptics audio`, если HD-haptics включены;
5. лишь затем вызывает `steam://rungameid/601150`.

Тайм-аут или отрицательная диагностика останавливают мост и не запускают игру в
заведомо дефолтном состоянии.

## Точные адаптивные курки

Значения получены из функций PS5-версии и переведены в нативный USB-отчёт DualSense.

### Nero

`Special2` / Exceed использует Vibration-effect: позиция 0, амплитуда
`clamp(int(max(analog * 0.5, 0.2) * 8), 1, 4)`, частота 76. Поэтому курок не является
просто постоянной стенкой: характер и амплитуда меняются по мере хода L2/R2.

`AttackL` использует `Weapon(4, 8, 4)`. Сторона назначается только после игрового
события с фактически нажатым L2/R2. Если Blue Rose остаётся на лицевой кнопке,
адаптивного эффекта для неё нет.

### Dante

Таблица `AttackL` по `weaponL_ID`:

| ID | Эффект |
| --- | --- |
| 0 | `Weapon(4, 5, 4)` |
| 1 | `Weapon(4, 8, 4)` |
| 2, 3, 4 | `Weapon(2, 8, 5)` |
| 5 | `Vibration(0, 4, 76)` |
| прочие | `Off` |

У V и игрового Vergil соответствующей PS5-ветки адаптивных курков нет, поэтому
`Authentic` оставляет оба курка свободными.

## Оригинальные HD-haptics

Мост содержит все 12 WAV, найденных в PS5 haptic soundbank, и применяет извлечённые
gain, pitch, delay и loop. Каналы динамика 1/2 остаются беззвучными; каналы 3/4 идут
на левый и правый тактильные voice-coil приводы DualSense при 48 кГц.

| № | Событие | Файл | Параметры |
| ---: | --- | --- | --- |
| 0 | Coyote-A | `87828053.wav` | stereo, +3 dB |
| 1 | Blue Rose | `683314104.wav` | stereo, 0 dB |
| 2 | Judgment Cut JR | `297926011.wav` | stereo, +5 dB |
| 3 | Ebony | `511441928.wav` | mono, +2 dB |
| 4 | Ivory | `1040252522.wav` | mono, +2 dB |
| 5 | Judgment Cut | `193630586.wav` | stereo, -1 dB, +300 cents |
| 6 | Beowulf impact | `752139616.wav` | mono, +8 dB, delay 0.1 s |
| 7 | Mirage loop | `310261087.wav` | mono, +5 dB, loop |
| 8 | Mirage end | `748704802.wav` | mono, +6 dB |
| 9 | Beowulf pre | `317387691.wav` | stereo, 0 dB, -250 cents, delay 0.3 s |
| 10 | Yamato return | `564764444.wav` | mono, -96 dB |

Отдельных именованных PS5-сэмплов для удержания заряда Blue Rose, EX-Act, MAX-Act или
каждого обычного удара в soundbank нет. В `Authentic` эти действия не получают
синтетическую подмену. Остальная отдача воспроизводится из настоящих PC-команд
`app.PadShake` и `setMotorPower`; watchdog 180 мс гасит мотор, если игра не прислала
финальный ноль.

## Authentic и Enhanced

`Authentic` — значение по умолчанию. Оно использует точные курки, цвета, именованные
PS5-сэмплы и штатные моторные команды PC-версии.

`Enhanced` дополнительно синтезирует отличимые импульсы по `attackHitCore` для Nero,
Dante, V и Vergil, импульс входящего урона и красную пульсацию при HP ниже 25%. Эти
эффекты удобны, но не маркируются как перенос из PS5.

## Интерфейс и режим «Пустота»

PC-бинарник всегда обращается к узлам `c_XB1`/`s_c_XB1`, даже когда текстура заменена
на PlayStation. Простая замена картинки поэтому показывала DualSense, но интерактивные
зоны оставались в геометрии Xbox: левый стик сверху, крестовина снизу.

Исправлены два GUI-ресурса:

- `ui4002.gui.270020` — экран управления;
- `ui8013.gui.270020` — обучение/«Пустота».

Для каждого соответствующего Xbox-узла скопированы из внутреннего PS4-узла position,
rotation, scale, size, control point, UV sequence/pattern, tiling и ключи clip tracks.
Проверка после повторного чтения GUI подтверждает, например:

- `s_c_XB1/LStP`: `(252, 322)`, pattern 13;
- `s_c_XB1/DirAll`: `(183, 230)`, pattern 9.

Это координаты PS-разметки: крестовина сверху слева, левый стик снизу слева. Три TEX
показывают значки PlayStation и реальную форму DualSense; GUI и TEX ставятся loose-файлами.
Для двух GUI установщик обнуляет только пары filename-hash в таблице
`re_chunk_000.pak`, иначе RE Engine продолжает предпочитать архивный GUI. В manifest
сохраняются индекс, смещение и оба исходных хеша каждой записи; payload не меняется.

## Установка, журнал и откат

Установщик хеширует все цели, сохраняет существовавшие версии под
`DMC5DualSense\backup` и пишет `install-manifest.json`. Удаление идёт в обратном порядке:
восстанавливает backup либо удаляет только файл, созданный пакетом. Изменённые после
установки конфиги и логи сохраняются. При удалении две GUI-записи PAK возвращаются к
исходным хешам, если их тем временем не изменила другая программа. `DevilMayCry5.exe`,
ресурсный payload PAK и сохранения не меняются.

## Граница локального использования

Исходники моста и плагина находятся в `Source`; лицензии сторонних открытых компонентов —
в `Licenses`. Собранные UI и haptic-ресурсы содержат данные игры и предназначены для
личного использования с принадлежащими владельцу копиями DMC5. Публичное распространение
готового пакета не предусмотрено.
