# Архитектура DMC5 DualSense Layer

## Назначение

Мод добавляет Steam-версии Devil May Cry 5 полноценную поддержку DualSense:
адаптивные курки, расширенную тактильную отдачу, обычную боевую вибрацию,
цветовую индикацию персонажей, значки PlayStation и изображение DualSense в
экране управления и режиме «Пустота». Профиль `Authentic` воспроизводит
поведение контроллера PS5-версии, а `Enhanced` добавляет необязательные
авторские импульсы.

## Поток данных

```text
DMC5 / RE Engine
  ├─ активный персонаж и игровое состояние
  ├─ события оружия и действий
  └─ штатные команды вибрации
            │
            ▼
REFramework.NET plugin
            │ UDP 127.0.0.1:27105
            ▼
DMC5DualSense.Bridge.exe
  ├─ adaptive triggers ──► Steam Input ──► L2/R2
  ├─ character colors ───► Steam Input ──► lightbar
  ├─ ordinary rumble ────► Steam Input ──► motors
  ├─ advanced haptics ───► WASAPI ───► DualSense actuators

DMC5 input ◄───────────── Steam Input ◄──────────── physical DualSense
```

Plugin только наблюдает за игровым состоянием и отправляет локальную
телеметрию. Штатный Steam Input полностью владеет вводом DMC5 и тачпадом. Bridge
использует официальный output API Steam Input и не создаёт виртуальный controller.
UDP доступен только через loopback.

## Запуск и ввод

Steam Input для DMC5 остаётся включённым. Launcher запускает Bridge только для
текущей игровой сессии, затем открывает DMC5 и гарантированно завершает Bridge
после выхода из игры. Постоянный watcher, запись автозапуска, отдельная служба и
виртуальный геймпад не создаются. Фоновое консольное окно и стартовая панель
REFramework скрыты.

## Возможности контроллера

- Nero: динамический Exceed и сопротивление Blue Rose при назначении действия на
  L2 или R2;
- Dante: при назначении огнестрельного оружия на L2/R2 сопротивление курка
  меняется вместе с выбранным оружием;
- V: фиолетовая подсветка и штатная боевая вибрация;
- Vergil: бирюзовая подсветка, штатная вибрация и поддерживаемые расширенные
  события оружия;
- все персонажи: обычная отдача ударов, урона и других событий DMC5.

Сторона L2/R2 определяется напрямую из действующей раскладки DMC5 через
`app.PadManager`. События выстрела не участвуют в определении привязки, поэтому
смена оружия на курке не может ошибочно включить сопротивление. Переназначение
применяется во время игры без перезапуска.

Поддерживаемые расширенные события включают Blue Rose, Coyote-A, Ebony, Ivory,
Judgment Cut, Beowulf, Mirage и Yamato. Обычные удары, удержание Blue Rose,
EX-Act и MAX-Act используют штатную отдачу DMC5, если игра её создаёт.

## Интерфейс

Мод заменяет Xbox-подсказки на PlayStation и показывает DualSense вместо
Xbox/DualShock 4. Положение крестовины, стиков, лицевых кнопок, L1/L2/R1/R2,
тачпада, Create и Options согласовано с реальной геометрией контроллера. Эти же
координаты используются интерактивной подсветкой в меню управления и «Пустоте».

## Установка и откат

Установщик создаёт резервные копии и `install-manifest.json`, поддерживает
автоматическое обновление предыдущей версии и сохраняет пользовательский
`config.json` вместе с диагностическими журналами. Деинсталлятор восстанавливает
предыдущее состояние файлов и не затрагивает сохранения.

`DevilMayCry5.exe` не заменяется. Мод не содержит исполняемый файл игры,
сохранения или средства обхода DRM и требует собственную Steam-копию DMC5.

## Воспроизводимая поставка

`Tools/Build-Release.ps1` запускает тесты, проверяет входные файлы, публикует
self-contained Bridge и Launcher, создаёт `release-manifest.json`,
детерминированный ZIP и `CHECKSUMS.txt`. GitHub Actions независимо собирает
публичные проекты и выполняет тесты ввода и адаптивных курков.
