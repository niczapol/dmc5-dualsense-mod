# DMC5 DualSense

[English](README.md) | [Русский](README_RU.md)

Полная поддержка DualSense для Steam-версии Devil May Cry 5 на Windows:
адаптивные курки, расширенная тактильная отдача, штатная боевая вибрация,
цвета подсветки персонажей, значки PlayStation и выровненное изображение
DualSense в настройках управления и режиме «Пустота».

## Какую версию скачивать?

| Версия | Рекомендация | Что устанавливать дополнительно |
| --- | --- | --- |
| **Native C++** | **Основная и рекомендуемая версия. Сначала используйте её.** | Ничего |
| Managed C# fallback | Запасной вариант на случай, если C++-версия не запустится именно на вашем компьютере. Логика контроллера та же, но встроенный runtime заметно увеличивает архив. | Ничего |

Обе версии находятся в [GitHub Releases](https://github.com/niczapol/dmc5-dualsense-mod/releases).
Не устанавливайте их одновременно. Если запустить один установщик поверх
другого, старая реализация будет безопасно заменена, а настройки и журналы
сохранятся.

## Что реализовано

- адаптивные курки с учётом текущих назначений управления в DMC5;
- расширенная тактильная отдача для поддерживаемых событий Nero, Dante и Vergil;
- штатная боевая вибрация DMC5 для всех персонажей, включая V;
- отдельные цвета световой панели для каждого персонажа;
- значки PlayStation и корректно выровненные схемы DualSense;
- стабильный тачпад, кнопки, стики и переназначения через штатный Steam Input;
- скрытые Launcher и Bridge, работающие только во время игровой сессии;
- обратимая установка с резервными копиями, хешами и точным откатом PAK.

## Требования

- Windows 10 или 11, x64;
- лицензионная Steam-версия Devil May Cry 5;
- DualSense, подключённый по USB;
- Steam Input включён или оставлен в режиме «Использовать настройки по умолчанию».

USB нужен для четырёхканального аудиовыхода расширенной хаптики. На время игры
закройте PlayStation Accessories, DS4Windows, DualSenseX и похожие утилиты.

Обычные DualSense семейств CFI-ZCT1 и CFI-ZCT2 поддерживаются через абстракцию
PS5-контроллера в Steam, поэтому мод не привязан к конкретной внутренней ревизии
или USB PID. DualSense Edge распознаётся тем же output-путём и новым matcher
аудиоустройства, но физический тест полного набора функций на Edge ещё не
завершён. Полная отдача по-прежнему требует USB.

## Установка

1. Скачайте ZIP **Native C++** из последнего GitHub-релиза.
2. Полностью распакуйте архив в обычную доступную для записи папку.
3. Закройте DMC5 и запустите `INSTALL-DMC5-DualSense.cmd`.
4. Оставьте Steam Input для DMC5 включённым либо в режиме по умолчанию.
5. Вставьте скопированную установщиком строку в
   `Steam → Devil May Cry 5 → Свойства → Параметры запуска`.
6. Подключите DualSense по USB и запускайте игру обычной кнопкой «Играть».

Если C++-версия не запускается, скачайте ZIP **Managed C# fallback** и точно
так же запустите его установщик. Отдельно ставить .NET не нужно — необходимый
runtime уже находится внутри fallback-архива.

Подробности: [русский гайд](Native/Package/README_RU.md),
[английский гайд](Native/Package/README_EN.md) и [история изменений](CHANGELOG.md).

## Как работает мод

Единственным владельцем игрового ввода остаётся Steam Input: он передаёт DMC5
кнопки, стики, переназначения и физический тачпад. Мод не перехватывает ввод и
не создаёт виртуальный геймпад. Сеансовый Bridge отправляет через Steam API
только эффекты курков, цвет подсветки и обычную вибрацию, а расширенную хаптику
воспроизводит через четырёхканальный WASAPI. После закрытия DMC5 не остаётся
службы, автозапуска, watcher или фонового процесса.

## Воспроизводимая сборка

Основная C++-версия использует закреплённые LLVM-MinGW и заголовки REFramework:

```powershell
powershell -ExecutionPolicy Bypass -File .\Native\Prepare-Dependencies.ps1
powershell -ExecutionPolicy Bypass -File .\Native\build-package.ps1 -Version 1.6.0
```

C# fallback собирается с .NET 10 SDK:

```powershell
powershell -ExecutionPolicy Bypass -File .\Tools\Build-Release.ps1 `
  -Version 1.6.0
```

Для финальной упаковки отдельно предоставляются UI- и haptic-файлы из
`release-assets.json`; сборщик проверяет точный размер и SHA-256 каждого входа.
Готовые архивы для игроков самодостаточны: .NET, ViGEm, виртуальный драйвер и
инструменты сборки устанавливать не требуется.
