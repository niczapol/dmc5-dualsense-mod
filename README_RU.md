# DMC5 DualSense

[English](README.md) | [Русский](README_RU.md)

Полная поддержка DualSense для Steam-версии Devil May Cry 5 на Windows:
адаптивные курки, расширенная тактильная отдача, штатная боевая вибрация,
цвета подсветки персонажей, значки PlayStation и выровненное изображение
DualSense в настройках управления и режиме «Пустота».

## Какую версию скачивать?

Сначала скачайте **[Рекомендуемую версию — лёгкую](https://github.com/niczapol/dmc5-dualsense-mod/releases/download/v1.7.3/DMC5DualSense-Native-1.7.3-win-x64.zip)**
(сборка на C++). Если она не запускается именно на вашем компьютере, используйте
**[Версию для совместимости — резервную](https://github.com/niczapol/dmc5-dualsense-mod/releases/download/v1.7.3/DMC5DualSense-Managed-1.7.3-win-x64.zip)**
(сборка на C#). Обе версии реализуют одинаковое поведение контроллера. Резервный
архив значительно больше из-за встроенного .NET runtime; отдельно устанавливать
дополнительные компоненты не требуется.

Не устанавливайте их одновременно. Если запустить один установщик поверх
другого, старая реализация будет безопасно заменена, а настройки и журналы
сохранятся.

## Что реализовано

- адаптивные курки с учётом текущих назначений управления в DMC5;
- расширенная тактильная отдача для поддерживаемых событий Nero, Dante и Vergil;
- штатная боевая вибрация DMC5 для всех персонажей, включая V;
- отдельные цвета световой панели для каждого персонажа;
- значки PlayStation и корректно выровненные схемы DualSense;
- автоматический скрытый запуск Bridge из игрового плагина без команды Steam и
  постоянной фоновой службы;
- обратимая установка с резервными копиями, хешами и точным откатом PAK.

## Требования

- Windows 10 или 11, x64;
- лицензионная Steam-версия Devil May Cry 5;
- DualSense, подключённый по USB;
- Steam Input включён или оставлен в режиме «Использовать настройки по умолчанию».

USB — единственный полностью поддерживаемый и физически проверенный вариант.
Bluetooth считается экспериментальным: кнопки, стики, тачпад и переназначения
должны продолжить работать через Steam Input, но вывод адаптивных курков,
подсветки и обычной вибрации этим модом по Bluetooth нами не проверен и не
гарантируется. Расширенная хаптика в текущей реализации по Bluetooth работать
не может, поскольку Windows не создаёт необходимый четырёхканальный аудиовыход
DualSense. Sony также указывает требование USB для хаптики на ПК в
[официальной справке по совместимости](https://www.playstation.com/en-us/support/hardware/pair-dualsense-controller-bluetooth/).

На время игры закройте PlayStation Accessories, DS4Windows, DualSenseX и
похожие утилиты.

Обычные DualSense семейств CFI-ZCT1 и CFI-ZCT2 поддерживаются через абстракцию
PS5-контроллера в Steam, поэтому мод не привязан к конкретной внутренней ревизии
или USB PID. DualSense Edge распознаётся тем же output-путём и новым matcher
аудиоустройства, но физический тест полного набора функций на Edge ещё не
завершён. Полная отдача по-прежнему требует USB.

## Установка

Установка обеих версий полностью одинакова:

1. По ссылкам выше скачайте **Рекомендуемую версию — лёгкую** или, если она не
   работает на вашем ПК, **Версию для совместимости — резервную**.
2. Полностью распакуйте архив в обычную доступную для записи папку.
3. Закройте DMC5 и запустите `INSTALL-DMC5-DualSense.cmd`.
4. Оставьте Steam Input для DMC5 включённым либо в режиме по умолчанию.
5. При обновлении со старой версии удалите её строку
   `DMC5DualSense.Launcher.exe` из параметров запуска Steam.
6. Подключите DualSense по USB и запускайте игру обычной кнопкой «Играть».

Параметры запуска Steam модификации не нужны. REFramework загружает игровой
плагин, тот скрыто запускает Bridge именно для текущего процесса DMC5 и
закрывает его вместе с игрой. Launcher остаётся в комплекте только как
резервный вариант совместимости.

Вложенный `dinput8.dll` — неизменённая закреплённая официальная сборка
REFramework; уникального кода DMC5DualSense в ней нет. Если в игре уже находится
другая распознанная сборка REFramework, установщик сохраняет её и добавляет
только плагин и ресурсы нашего мода. При обнаружении неизвестного `dinput8.dll`
обычный установщик сам предложит замену. Ответ `Y` сохранит точную резервную
копию и заменит DLL, а `N` отменит установку, не меняя существующий файл.
При удалении мода заменённая DLL будет точно восстановлена. Рекомендуемый нативный плагин использует
стабильную часть REFramework Plugin API 1.10; резервной managed-версии требуется
Plugin API 1.15, поэтому со старым фреймворком ей может понадобиться режим замены.
